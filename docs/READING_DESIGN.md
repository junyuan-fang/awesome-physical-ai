# 阅读结构与维护约定

首页服务三种意图：找到方向、跟进近期工作、进入资源库。阅读深度分三层：

1. **首页**：固定 5 篇近期精选、研究方向入口、资源入口。正文上限 130 行、12 KB，不放完整论文清单。
2. **分类浏览**：按方向分页，每页最多 15 篇。只显示标题、日期、阅读优先级、代码状态和短介绍。
3. **论文详情**：以 arXiv ID 作为稳定文件名，保留完整摘要、全部作者单位、C/E/O/T 评分依据、开放状态、待核查项和历史记录。

Top 20 独立成页；一页式标题索引支持全文查找；每日、每周、每月报告是历史快照。
数据、仿真器、基准、工具与公司各自成页。资源关联论文每个展开块最多 10 条。
首页旧分类锚点、索引旧类别和资源锚点保留，旧链接仍可引导读者到新位置。

## 自动生成

`data/*.yaml` 是唯一结构化数据源。`templates/` 定义展示，`scripts/generate_readme.py`
生成 README、目录、分页、详情和报告导航。`docs/.generated-pages.json` 记录生成文件；
只清理带生成标记、位于 docs 下、已不在输出清单内的旧页面，不删除人工专题。
精选窗口锚定最近完成扫描日，避免同一份数据在不同时刻生成不同页面。

每日 runner、README 工作流和开源复查工作流都要提交全部生成页面。测试检查首页预算、
分类页上限、论文完整性、相对链接与锚点、重复生成一致性。评分算法和已有论文数据不因版式调整而改变。

## 参考与取舍

- [Awesome 总目录](https://github.com/sindresorhus/awesome)：分类导航和简短条目便于定位。
- [Awesome Python](https://github.com/vinta/awesome-python)：按需求组织分类，用短描述帮助读者选择。
- [Awesome Embodied AI](https://github.com/wadeKeith/Awesome-Embodied-AI)：围绕具身方向组织资源，并控制代表条目数量。
- [Awesome Physical AI](https://github.com/keon/awesome-physical-ai)：机器人基础模型、VLA、世界模型等方向可作为清晰入口。

这些仓库有的仍采用很长的单页。本仓库持续积累中文评审，选择分页加稳定详情页，
让首页长度不随论文数增长。借鉴的是信息组织方式，未复制对方的论文内容或重新收录条目。
