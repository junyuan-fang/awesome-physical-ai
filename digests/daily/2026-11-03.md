### 1. OpenNWM: A Generalist Navigation World Model with Latent Action Pretraining — 👀 值得关注

- **时间：** 2026-11-01（[arXiv](https://arxiv.org/abs/2611.01844)）；**迟发现**
- **评分：** C4（视觉和物理联合监督的潜动作预训练连接异源无动作视频与导航规划，并提供有规模的 NavAnywhere 数据资源。） / E4（第4节有域内/域外预测、轨迹规划、监督和预训练消融；证据覆盖多个数据来源，但未将离线轨迹结果夸大为真机闭环可靠性。） / O4（已核对训练代码、官方 HF 检查点和数据文件目录；NWM/LAM 许可明确，数据保留上游条件，未做全量下载复现故不评 5。） / T3（未独立核验作者近五年的完整相关成果序列，默认 3。） = **77/100**；**优先级：** 👀 值得关注
- **作者/团队单位：** CASIA；UCAS；HKUST(GZ)；UC Berkeley；Tongji University
- **分类：** `world-model` · 核心 · model
- **核心内容：** 为利用缺少机器人动作标注的导航视频，OpenNWM 先以视觉预测和物理运动监督共同学习潜动作，再训练潜动作条件的扩散世界模型，最后适配可执行的路径点动作；在线规划变量仍是真实动作，并非任意潜向量。作者整理来自15种来源、1750万帧的 NavAnywhere，覆盖人、地面机器人和无人机视角，在四种域内及多种域外数据上比较预测和规划。报告的域内平均 LPIPS 为0.368，NWM 为0.405；SCAND 路径绝对误差为0.98，对照 NWM 为1.01，另有预训练和监督形式消融。结果支持异源视频改善动力学表征，但视觉质量与导航控制成功并不等价，部分域外指标并非最优，论文轨迹评估也不构成新真机闭环成功率。代码、检查点和数据目录已公开；不同组件及上游数据许可各异，真实 Go2 部署仍列在项目后续工作中。
- **发表状态（核验：2026-11-05）：** arXiv 预印本；未检索到正式录用记录
- **开源状态（首次核查：2026-11-05；last_check：2026-11-05）：** 已公开实质相关代码，[仓库](https://github.com/OpenSpace-Lab/OpenNWM)；权重 open，数据 open，许可 CC-BY-NC-4.0 AND Apache-2.0。官方仓库有 LAM/NWM 训练与评测实现。https://huggingface.co/LittleB0sS/OpenNWM API 确认 ungated、检查点/配置/校验和；https://huggingface.co/datasets/LittleB0sS/NavAnywhere 为 ungated 且有266个文件条目。NWM 为 CC-BY-NC-4.0，LAM 为 Apache-2.0；数据卡列 other 并要求遵循上游许可，非统一无限制商用。未执行全量下载或复现。

### 2. ODE Policy: Robot Learning via Action Dynamics, Not Actions — 👀 值得关注

- **时间：** 2026-11-01（[arXiv](https://arxiv.org/abs/2611.01729)）；**迟发现**
- **评分：** C4（方法将动作导数学习、路径监督与跨块积分统一，并可嵌入 IL、RL、VLA 和 WAM，方法增量清晰。） / E5（第5至7节覆盖多基准、强基线、结构消融、扰动泛化及四类平台14项真机任务，证据广度达到高档；真机单项次数仍有限。） / O3（Apache-2.0 仓库包含训练、基线、评测及部分真机/VLA 分支；未确认作者模型检查点和新增真机数据可下载。） / T3（近五年相关成果尚未独立梳理，默认 3，不把实验广度重复计入团队分。） = **76/100**；**优先级：** 👀 值得关注
- **作者/团队单位：** MARS Lab, Nanyang Technological University
- **分类：** `rl-il` · 核心 · method
- **核心内容：** 为缓解动作块不连续及迭代生成的计算成本，ODE Policy 学习动作随物理时间演化的向量场，从当前动作积分得到后续轨迹，以整段路径误差监督而不直接拟合带噪导数。收缩性正则和跨块延续进一步约束初值扰动，并通过混合速度头容纳多模态行为。作者在 LIBERO、扰动测试、强化学习以及 VLA/WAM 适配中比较多种策略，并在四类平台的14项真机任务上验证。在 Franka 每任务40条演示、20次测试的条件下，袜子折叠成功15/20，最佳对照8/20；插入为14/20，对照4/20。结果支持连续时间参数化改善学习效率及接触任务执行，但小样本真机结果仍有统计不确定性，摄像机变化会使部分视觉策略失败；动作头加速不能直接等同于完整系统延迟下降，也没有保证真实机械系统始终平滑稳定。
- **发表状态（核验：2026-11-05）：** arXiv 预印本；未检索到正式录用记录

- **评分：** C4（技术报告把几何参照、程序化工具、预览与回执串成机器人执行系统，并给出跨任务复用机制。） / E4（第6节有6300次 RoboDojo 评测、RoboCasa 子集及工具消融；全部在暂停推理时物理演化的仿真设置中完成。） / O3（官方 MIT 仓库包含核心执行、工具、配置和环境安装说明，构成实质代码；外部模型服务及完整评测资产不属于可复现权重发布。） / T3（未核实该技术团队近五年的独立相关产出，按默认 3 记录。） = **71/100**；**优先级：** 👀 值得关注

- **分类：** `foundation-general` · 核心 · system
- **核心内容：** 为减少机器人语言智能体的几何误解和未经验证的长动作，Auriga 维护任务信念与观测证据，把指尖参照的动作命令、标定几何、执行前预览和执行后回执纳入统一接口，并通过单一执行入口约束停止误差与抓取状态。系统不依靠目标任务微调或演示，开发中经历多轮跨任务诊断。作者使用 GPT6 Astra，在 RoboDojo 的42项任务、6300次模拟评测中报告57.7%成功率和64.0分，所引参考系统为22.5%和29.0分；在 RoboCasa365 的 Target50 子集250次测试中成功率73.2%，组合与未见任务仍弱于原子任务。移除预览或程序化工具会降低表现，支持执行设计的重要性。但推理期间模拟物理暂停，结果没有验证真实时间约束或真机鲁棒性；开发任务与评测诊断的边界也限制零样本泛化解读，且系统依赖闭源模型服务。

### 5. GoalDex: Learning Image-Goal-Conditioned Policies for Dexterous In-Hand Manipulation — 👀 值得关注

- **时间：** 2026-11-01（[arXiv](https://arxiv.org/abs/2611.02171)）；**迟发现**
- **评分：** C4（目标姿态对比表征与特权教师、循环视觉学生结合，针对遮挡下图像目标手内重定向给出明确方法增量。） / E4（方法和实验含多种视觉/姿态基线、组件消融、模拟扩展及五物体100次真机测试；未见类别仍是边界。） / O2（论文给出项目入口及发布承诺，但本次项目访问未成功，未核实实质代码、权重或数据，按承诺档计 2。） / T4（论文明确承接同作者在 ViserDex（RSS 2026）的视觉灵巧操作工作，可核实相关方向积累，给 4。） = **68/100**；**优先级：** 👀 值得关注
- **作者/团队单位：** ETH Zurich；NVIDIA
- **分类：** `manipulation` · 核心 · method
- **核心内容：** 为摆脱部署时精确估计物体姿态的依赖，GoalDex 用目标图像描述所需朝向，先训练读取特权物理状态的强化学习教师，再把技能蒸馏给仅接收视觉与本体感觉的循环学生。目标编码器通过连续姿态对比学习区分相近方向，学生同时重建物体物理状态，以记忆补偿遮挡和接触歧义。作者在模拟中比较姿态控制、通用视觉特征及记忆、重建等消融，并在五种真实物体各20个目标上测试：图像目标策略合计成功80/100，最强姿态对照27/100。结果提示直接学习目标相关视觉表示有助于绕过姿态估计误差，但目标图像生成仍依赖物体几何与分割，验证集中于掌心向上的手内重定向；扩大到25种模拟物体需要增加训练规模，尚未解决完全未见物体类别泛化。项目入口存在，但本次未能核实代码和资产发布。
