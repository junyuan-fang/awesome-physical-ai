# World-Action Models (WAM) / 世界-动作模型专题

> 纵向专题，不占每日扫描名额。评分、开放状态与链接以 [`data/papers.yaml`](../data/papers.yaml) 和 [`docs/index.md`](../docs/index.md) 为准；文中数字均为**作者报告**，不同基准/条件下的数字不横向比较。

## 1. 是什么，边界在哪

WAM 在同一个模型里联合预测「未来世界状态」与「可执行动作」，让动作生成受环境动力学约束。与相邻概念的边界：

- **经典世界模型 / MBRL**：学状态转移，用规划或 RL 求动作；动作不是模型直接输出。
- **动作条件视频生成**：以动作为条件生成未来视频，但不一定输出可执行控制。
- **反应式 VLA**：观测→动作，通常没有显式未来预测目标。
- **WAM**：联合建模未来与动作。有的先想象后逆动力学，有的端到端联合去噪，有的只学潜空间。

两篇综述可作为入口：

- [World Action Models: A Survey](https://arxiv.org/abs/2606.20781)（已跟踪，63/100）——界定 WAM 与 VLA / 视频世界模型的边界，按「渲染后解码 / 仅潜空间 / 无视频生成」三类与四轴结构梳理。
- [World-Action Models for Robot Learning and Control: A Survey](https://arxiv.org/abs/2609.16074)（2026-09，已评审，因 2026-10-22 轮次上限暂缓收录）——约 66 个系统、49 个数据集/仿真器/基准的索引，并给出成功率、SPL、ADE/FDE 等指标定义。

## 2. 设计轴

比较 WAM 时看五个轴：

1. **表示**：RGB 视频 / 深度与 3D 点图 / 潜空间 / 触觉 / 骨架与运动学。
2. **转移建模**：联合预测 vs 先想象后逆动力学 vs 只学潜状态。
3. **架构**：端到端单流 vs 双系统（慢规划 + 快动作）。
4. **训练**：视频预训练 → 机器人后训练；是否使用无动作视频。
5. **实时性**：迭代去噪 / 因果流式 / 蒸馏少步 / 缓存复用。

## 4. 资源与评测

- **数据**：Xp-Data / Xp-Teleop（Ropedia W0）、OpenWAM-α（6,369 h）、Rynn4DDataset、GRAIL 生成数据、AgiBot World。
- **基准**：RoboTwin 2.0、LIBERO / LIBERO-Plus、RoboCasa / RoboCasa365、AgiBot World、DreamDojo、DOMINO、EBench、PAWBench、KineBench。
- **评测口径**：视频预测指标（PSNR/SSIM/LPIPS/FVD）与下游控制成功率不能互相替代；WAM 作为策略评估器时，要报告与真机结果的相关性（如 WEAVER 的 0.870、OSCAR 的 RoboArena 相关性）。

## 5. 开放问题

- **动作保真 vs 视觉保真**：预测得好看不等于动作可执行。
- **长时程**：上下文变长后增益是否持续（Long-WAM 在 38.4 s 出现回落）。
- **跨具身**：骨架、点图、潜动作三条统一路线仍未收敛。
- **实时性**：蒸馏少步、缓存复用、因果流式是当前主流。
- **评测协议**：缺少统一的「世界模型即策略评估器」标准。
- **开放状态**：多数 WAM 只发布推理代码或权重，训练/数据仍闭源（见各条目 `open`）。
